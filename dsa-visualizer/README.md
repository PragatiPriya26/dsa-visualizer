# DSA Visualizer

An interactive web-based visualization tool for understanding sorting algorithms.

## 🚀 Live Demo

[👉 Try DSA Visualizer Live]https://dsa-visualizer-kohl-six.vercel.app 

## ✨ Features

- Bubble Sort visualization
- Selection Sort visualization
- Insertion Sort visualization
- Merge Sort visualization
- Real-time sorting animations
- Pause / Resume controls
- Reset and generate new arrays
- Adjustable speed
- Multiple array types
- Algorithm trace panel
- Time and space complexity information
- Responsive design
